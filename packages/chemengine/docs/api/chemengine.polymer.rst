Polymer chemistry engine (M39)
=============================

``chemengine.polymer``
-----------------------

Deterministic, graph-based polymer chemistry over the shared
:class:`~chemengine.core.graph.MolecularGraph` abstraction (no SMARTS, no
RDKit, no external chem libraries, no string matching): repeat-unit-form
(``*CC*``, PET) and terminal-chain-form oligomer representations, connection
points, repeat-unit extraction, addition/condensation classification,
end-group detection, structural degree of polymerization, and an 8-case
reference oracle.
